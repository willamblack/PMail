## 0.08 — 上游历史修复边界补全

核对上游 v2.9.1 至 master@0ff28fb 后，修复定制分支中仍存在的五组问题：

- 附件：mixed/related 正文后的命名文本或 HTML 部件不再覆盖正文，兼容正常 inline 正文和编码文件名。
- 日期：支持更多合法邮件 Date 格式，不再误替换为当前时间。
- IMAP：IDLE 退出完成清理后再返回，避免快速重入时通知注册被旧清理删除。
- 插件：禁止已经退出的进程重新注册，旧进程退出不误删同名新实例。
- 发件：按规范化域名聚合收件人，每域只查一次 MX，避免等优先级 MX 轮换造成分组和失败结果互相覆盖。

保留单管理员 Catch-All、SQLite、原配置与 `/work/config` 挂载；无需数据库迁移。
没有改前端，也没有恢复上游 STORE Deleted 立即删除邮件的行为。

本地已通过完整 Go 测试、vet、全包 race、前端状态辅助回归，并重复验证 IDLE 进出。
这不代替生产 VPS、真实收发邮件或 iOS/Safari 实机验收。

默认交付流程统一为：先推送定制分支，通过检查后同步 master，再发布 Release。
正式 Release 只触发一套 Docker 发布，同时更新版本镜像和 latest；历史版本不覆盖。

```bash
docker pull ghcr.io/willamblack/pmail:0.08
```

升级前请停止写入并完整备份配置挂载目录，保持原挂载后重建容器。
从 0.06 或更早版本升级时需重新登录；SMTP 587 使用 STARTTLS，POP3 使用 995。
